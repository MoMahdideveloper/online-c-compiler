## 1. Core C Keyword Categories
- **Type Specifiers**: `int`, `char`, `float`, `double`, `void`, `_Bool`, `_Complex`
- **Storage Class Specifiers**: `auto`, `register`, `static`, `extern`, `typedef`, `_Thread_local`
- **Type Qualifiers**: `const`, `volatile`, `restrict`, `_Atomic`
- **Control Flow**: `if`, `else`, `switch`, `case`, `default`, `while`, `do`, `for`, `goto`, `break`, `continue`, `return`
