## 📂 Included Artifacts

1. **`onlineccompiler_postman_collection.json`**:
   - Ready for import into Postman Desktop, Web, or Newman CLI.
   - Includes sample compilation and memory pointer visualization requests.
   - Configured with required CORS headers (`Origin`, `Referer`).

2. **`openapi_spec.json`**:
   - Standard OpenAPI 3.0 schema.
   - Importable into SwaggerHub, RapidAPI, Redocly, and Postman API Network.

## 🚀 How to Publish to Postman Public Network

1. Open Postman -> Click **Import** -> Select `onlineccompiler_postman_collection.json`.
2. Right click the imported collection -> Click **Share Collection** -> **Make Public**.
3. Add tags: `c`, `compiler`, `gcc`, `developer-tools`, `education`.
4. Link to homepage: `https://onlineccompiler.com/`.
